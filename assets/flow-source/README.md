# Diagram sources

`graph.json` preserves the seven nodes, nine edges, and conditional review path from the skill's documented workflow. It describes a recommended workflow, not a deployed runtime. `assets.json` records the original local symbols, file hashes, and license notes.

The sun, crescent, and star are original explanatory artwork created for this repository. They are not official OpenAI or model logos. The artwork and graph use this repository's Apache-2.0 license.

Edit the self-contained `../orchestration-flow.svg` in an SVG editor; its named node and edge groups retain the structure and its title/description retain accessible relationship text. The PNG is the GitHub preview and must be regenerated after SVG edits. Keep the graph, manifest, and icons in sync when changing topology or artwork.

The initial PNG was exported at 2x with an already available Sharp renderer. No remote images or fonts are needed. Labels use a standard sans-serif font stack; the PNG fixes the rendered appearance.
